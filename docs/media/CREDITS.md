# Better PiP Minecraft demo credits

This 15-second video is an illustrative stock-footage composite. Minecraft and YouTube are not running in the recording. Cursor movements, browser chrome, PiP geometry, locking, and the association between a click and gameplay are edited illustrations, not a live verification of input routing. No desktop recording was made for this version.

The app picker uses the previously captured Better PiP interface with the sample source title and search text replaced. The movie continues across the browser-to-PiP transition. Overlay opacity is lowered to 52% in the final illustration to make the underlying gameplay visible; locking does not automatically change app opacity.
